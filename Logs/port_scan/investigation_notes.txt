----------------------------------------------------------
Investigation Summary
----------------------------------------------------------

During traffic monitoring, multiple TCP SYN packets were detected
originating from a single source IP.

The attacker attempted connections to numerous destination ports
within a short time period.

Analysis of conn.log confirmed repeated connection attempts,
while Wireshark packet captures verified SYN packets targeting
multiple services.

- Python Detection Script

----------------------------------------------------------
Recommendation
----------------------------------------------------------

• Monitor repeated reconnaissance attempts.
• Block malicious source IP if confirmed.
• Enable firewall logging.
• Configure IDS/IPS rules to detect abnormal scanning activity.
